# basiclinux-compiler
A simple tool that uses GitHub Actions to compile the linux and make a pure linux.  
This uses Linux 6.6.60, BusyBox.  
## How to run?
Go "Actions" in top tab, and search for "Run workflow" and press/click "Run workflow".
